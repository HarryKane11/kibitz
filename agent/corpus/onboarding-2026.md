# 신규 고객 온보딩 절차

문서 ID: ONB-2026-R3 · 최종 개정 2026-05-10

## 1. 표준 일정

| 단계 | 소요 | 담당 |
|---|---|---|
| 킥오프 | 1일 | CSM |
| 환경 프로비저닝 | 3일 | 인프라팀 |
| 데이터 연동 | 10일 | 솔루션 엔지니어 |
| 파일럿 운영 | 14일 | 고객 + CSM |
| 정식 전환 | 2일 | CSM |

총 표준 소요는 30영업일이다.

## 2. 고객 준비물

- 관리자 계정 2인 이상
- 연동 대상 시스템의 API 자격증명
- 데이터 스키마 명세

## 3. 파일럿 종료 기준

파일럿은 다음 세 조건을 모두 충족해야 종료한다.

1. 핵심 시나리오 3건 이상 성공
2. 응답 정확도 85% 이상
3. 고객 담당자 승인

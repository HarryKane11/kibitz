# WeAgent 서비스 수준 협약 (SLA) — 2026년판

문서 ID: SLA-2026-R2 · 최종 개정 2026-04-01

## 1. 가용성 보장

| 플랜 | 월간 가용성 | 크레딧 |
|---|---|---|
| Starter | 99.0% | 미제공 |
| Business | 99.5% | 10% |
| Enterprise | 99.9% | 25% |

가용성은 월간 총 분(minute) 대비 정상 응답 분의 비율로 계산한다.
계획된 정기 점검(월 1회, 최대 120분)은 산정에서 제외한다.

## 2. 응답 시간

- P50 지연: 340ms 이하
- P95 지연: 1200ms 이하
- P99 지연: 2800ms 이하

측정 지점은 API 게이트웨이 인그레스이며, 클라이언트 네트워크 구간은 포함하지 않는다.

| 심각도 | 최초 응답 | 해결 목표 |
|---|---|---|
| S1 (전면 장애) | 15분 | 4시간 |
| S2 (기능 저하) | 2시간 | 24시간 |
| S3 (일반 문의) | 1영업일 | 5영업일 |

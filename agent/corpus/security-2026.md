# WeAgent 보안 정책

문서 ID: SEC-2026-R1 · 최종 개정 2026-02-20

## 1. 인증

- 모든 API 요청은 JWT Bearer 토큰을 요구한다. 토큰 유효기간은 3600초다.
- 리프레시 토큰 유효기간은 30일이며, 사용 시 회전(rotate)된다.
- SSO는 SAML 2.0 및 OIDC를 지원한다. Enterprise 플랜 전용이다.

## 2. 데이터 격리

모든 조회 쿼리는 `org_id` 조건을 강제한다. 애플리케이션 레이어와 DB 레이어(RLS)에서
이중으로 검증하며, 두 계층 중 하나라도 누락되면 배포가 차단된다.

## 3. 암호화

- 전송 구간: TLS 1.3
- 저장 구간: AES-256-GCM
- 키 회전 주기: 90일

## 4. 감사 로그

감사 로그는 최소 365일 보관한다. 로그에는 행위자, 시각, 대상 리소스, 결과가 기록된다.
로그 자체는 수정 불가(append-only)하다.

## 5. 인증 취득 현황

- ISO 27001: 취득 (2025-11)
- SOC 2 Type II: 취득 (2026-01)
- ISMS-P: 심사 진행 중 (2026-09 예정)

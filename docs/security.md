# 보안

## 트레이스에 무엇이 들어가는가

**프롬프트 전문, 파일 경로, 프로젝트명, 도구 인자, 출력.** 실제 작업 내용이
그대로입니다.

즉 트레이스 파일은 소스 코드와 같은 수준으로 다뤄야 합니다.

## 이미 막아 둔 것

- `web/lib/mock/traces.json` — gitignore
- `web/.kibitz/` — gitignore
- `.env` — gitignore (`.env.example` 만 커밋)
- `.dockerignore` 가 트레이스를 이미지에서 제외 → 이미지를 배포해도 세션이 안 나감
- `GET /api/traces` 는 **요약만** 돌려줍니다 (본문 없음)
- SDK 의 LangChain 핸들러는 프롬프트를 기본으로 기록하지 않습니다

## 노출 전 확인

1. **인제스션 토큰을 설정하세요.**
   ```bash
   KIBITZ_INGEST_TOKEN=$(openssl rand -hex 32)
   ```
   없으면 `POST /api/traces` 가 열려 있습니다. 로컬 단독 사용을 기본으로 잡았기
   때문입니다 — 첫 5분이 설정 작업이 되지 않게.

2. **읽기 인증은 프록시에서.** Kibitz 자체에 로그인이 없습니다. 대시보드가 열려
   있으면 트레이스 전부가 열려 있습니다.

3. **커밋 전 확인.**
   ```bash
   git status --porcelain | grep -E 'traces\.json|\.kibitz'   # 아무것도 안 나와야 정상
   ```

4. **커밋 이력을 확인하세요.** 이 규칙이 생기기 전에 트레이스를 커밋한 적이
   있으면 gitignore 는 소급되지 않습니다.

## 키

- 코드에 키를 넣지 않습니다. 환경변수 또는 시크릿 매니저만.
- 서버 env 에 두면 브라우저가 키를 보지 않습니다 — 그쪽이 기본입니다.
- 브라우저에서 입력한 키는 그 요청 하나에만 쓰입니다. 저장하지 않고, 로그하지 않고,
  localStorage 에도 넣지 않습니다. 응답에도 담기지 않습니다 (설정 여부만 나갑니다).

## 탐지는 데이터를 밖으로 보내지 않습니다

여섯 판정 규칙은 전부 로컬 계산입니다. 선택적 모델 분석을 **명시적으로** 쓸 때만 — 버튼을 누를 때만 —
트레이스 요약이 선택한 제공자로 나갑니다. 분석을 안 쓰면 네트워크 호출이 없습니다.

나가는 것은 **판정과 근거값**이고 프롬프트·모델 출력 본문은 포함되지 않습니다. 보내기
전에 전문을 화면에서 읽을 수 있고, 도구 인자(파일 경로·질의)는 제거할 수 있습니다.
Ollama 를 고르면 아무것도 밖으로 나가지 않습니다. 상세: [analysis.md](./analysis.md)

Claude Code·Codex 계정 방식을 고르면 같은 브리프가 해당 CLI가 사용하는 제공자로
전송됩니다. Kibitz는 credential 파일이나 token 값을 읽지 않고, 로그인 상태와
일회성 분석 프로세스의 공개 출력만 받습니다. 분석 프로세스는 빈 임시 디렉터리에서
도구를 끄고 실행되며 세션 기록을 남기지 않습니다.

production에서 로컬 CLI 실행은 기본 비활성입니다. 명시적으로
`KIBITZ_ALLOW_LOCAL_CODE_AGENTS=1`을 설정한 서버에서만 로그인과 분석을 허용하세요.
이 설정은 서버 프로세스를 실행하는 OS 사용자의 AI 구독 예산을 쓸 수 있는 권한입니다.

## 읽기 API 를 노출한다면

`KIBITZ_READ_TOKEN` 을 설정하세요. `/api/runs`, `/api/failures`, `/api/skills`,
`/api/analyze` 가 `Authorization: Bearer` 를 요구합니다. **`/api/analyze` 는 특히
중요합니다** — 서버에 키를 두었다면 이 라우트가 그 키로 돈을 쓸 수 있는 입구입니다.
화면은 서버 액션을 쓰므로 토큰을 걸어도 그대로 동작합니다.

## 익명 방문자에게 열린 URL 이라면

`KIBITZ_PUBLIC_SITE=1` 을 설정하세요. 첫 화면이 랜딩으로 바뀌는 것 외에 셋이 잠깁니다:

- **붙여 넣은 API 키를 받지 않습니다.** 낯선 웹페이지에 키를 넣는 습관을 만들어 주면
  안 되고, 그 사이트가 언젠가 털리면 그 키도 함께 털립니다.
- **토큰 없는 수집을 거부합니다.** 설치본은 대개 localhost 라 열어 두지만, 공개 URL
  에서 그 기본값을 그대로 쓰면 아무나 트레이스를 밀어 넣습니다.
- **서버의 Claude Code·Codex 로그인을 쓰지 않습니다.** `KIBITZ_ALLOW_LOCAL_CODE_AGENTS`
  와 무관하게 꺼집니다 — 켜져 있으면 방문자 아무나 배포자의 계정 예산을 씁니다.

서버 env 에 둔 키는 계속 동작합니다. 그건 배포자가 자기 예산으로 한 선택이고,
브라우저는 그 키를 보지 않습니다. 자세한 대조표: [configuration.md](./configuration.md#배포-종류)

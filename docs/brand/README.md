# Kibitz brand notes

## Position

Kibitz is open-source tracing for long-running agents. It aims to replace the
core Langfuse tracing workflow while making request groups, decision paths,
context movement, evidence-backed findings, and counterfactuals first-class.
Observed trace data, derived metrics, persisted resources, and optional model suggestions must
always be labeled separately.

## Mark

The mark combines a `K` with a variation fork:

- the vertical stem is the recorded trace;
- the filled branch is the path the agent actually chose;
- the open branch is the counterfactual still available for inspection;
- the vermilion junction is the decision under review.

Production SVG: `web/public/brand/kibitz-mark.svg`

The generated exploration sheet is preserved in
`docs/brand/kibitz-mark-concepts.png`. The production mark is a manually
simplified SVG derived from its top-left concept, not the generated bitmap.

## Type and color

- UI and Korean: self-hosted Pretendard Variable, weight 45–920
- Code and telemetry: native UI monospace stack
- Light annotation: `#A4432B` on `#FFFFFF` — 6.15:1
- Dark annotation: `#FF7A55` on `#0A0B0D` — 7.66:1

The annotation color is brand language, not a new status color. Error and waste
continue to use the existing semantic tokens.
